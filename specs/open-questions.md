# Open Questions

Rule: if the spec is ambiguous, log it here, choose the **safest simplest** default, continue.
Mark `BLOCKING` only if you truly cannot proceed safely. Resolve by editing the spec, then move the entry to "Resolved".

Format: `- [Q-001] [BLOCKING?] question. Default chosen: ... (phase, date)`

- [Q-026] `fillPage` is optional and the empty-page copy is only in the edge cases. Default chosen: omitting `fillPage` runs one Scan. The Items screen always sends `fillPage: true`. A page with zero items and `hasMore` shows "Keep searching" as well as "Load more". (Phase 4, 2026-10-24)
- [Q-027] "Connection fingerprint" for column persistence is undefined. Default chosen: `localStorage` key `ds-columns:` plus the SHA-256 of `endpoint`, `region`, and table name. The value stores visibility and widths only. No credentials and no connection id. (Phase 4, 2026-10-24)
- [Q-028] Operator lists, the 200-column cap, and the GSI consistent-read control are underspecified. Default chosen: strings get comparisons, `between`, `begins_with`, `contains`, `not_contains`, `in`, `exists`, `not_exists`, and `type_is`. Numbers get the comparisons, `between`, `in`, `exists`, `not_exists`, and `type_is`. Binary gets equality, `begins_with`, `exists`, `not_exists`, and `type_is`. Booleans get equality, `exists`, `not_exists`, and `type_is`. Sets get `contains`, `exists`, `not_exists`, and `type_is`. Lists and maps get `exists`, `not_exists`, and `type_is`. The grid shows the first 200 columns and "Show more columns" reveals the rest. The Items screen has a consistent-read checkbox for the base table and no index picker. Density stays the existing overflow control. (Phase 4, 2026-10-24)
- [Q-029] A cursor must not be reused after the request shape changes. Default chosen: the cursor binds a hash of table, index, filters, joiner, projection, and consistent read. A mismatch is `400 VALIDATION`. Changing page size aborts the in-flight scan and starts over without that cursor. (Phase 4, 2026-10-24)
- [Q-030] Item size and `itemHash` need a canonical form. Default chosen: hash is SHA-256 base64url of canonical typed JSON with object keys sorted at every map, arrays left in order, and numbers left as strings. Size is the UTF-8 length of attribute names plus values (number text as written, binary as decoded bytes, bool and null as 1 byte, lists and maps as the sum of their children). The server rejects an item over 400 KB with `LIMIT_EXCEEDED` before calling DynamoDB. (Phase 5, 2026-10-25)
- [Q-031] Delete can send `expectedHash`, and a missing item has no specified response. Default chosen: delete by key only. A missing item returns `{ deleted: false }` and the UI says "Already deleted" with no Undo. Undo of a real delete sends `PUT` of `previousItem` with `ifNotExists: true`. (Phase 5, 2026-10-25)
- [Q-032] The AWS CLI copy could include credentials. Default chosen: the command is `aws dynamodb put-item` with `--table-name`, `--item`, `--region`, and `--endpoint-url` only when the endpoint is not the regional AWS host. Values are single-quoted. No access keys. (Phase 5, 2026-10-25)
- [Q-033] Batch delete is one JSON response, while the dialog wants progress and cancel. Default chosen: the client sends chunks of 25 keys, updates the dialog after each response, and cancel skips chunks that have not started. The server still retries `UnprocessedItems` inside a chunk and stops if the request aborts. (Phase 5, 2026-10-25)
- [Q-034] Layer-2 concurrency can be skipped on a large item, and the update response has no field for that. Default chosen: success may include optional `weakConcurrency: true`. The conflict dialog says the check is best-effort. Overwrite sends the same update without `expectedHash`. Reload calls `items/get`. (Phase 5, 2026-10-25)
- [Q-035] "Show request" could be built twice, once in the browser and once on the server. Default chosen: one pure key-condition function in `packages/shared`, used by the server route and the disclosure. The route still returns `request`, and the disclosure must match it. (Phase 6, 2026-10-26)
- [Q-036] PartiQL history and saved queries need a storage key, and the account id is not on the connection summary. - [Q-037] The seed has no LSI, and Scan/Query filter carry-over is only "unless the user opts in". Default chosen: do not add an LSI. - [Q-038] A PartiQL mutation's typed confirmation and `affected` count are unspecified. Default chosen: the dialog names the verb. - [Q-039] DynamoDB Local may not include a character position on a PartiQL syntax error, and the cost hint's loopback rule is the Scan rule. - [Q-040] Export "this view" could mean the rows already loaded, a new Scan/Query, or PartiQL, and only NDJSON has a specified summary line. - [Q-041] AC-7.5 asks for a 50,000-row import and bounded memory, and no RSS profiler is in the stack. Approval (2026-10-27) adds a generated import larger than 100 MB and asserts server RSS growth stays far below that file size. The numbers go in `specs/progress.md`. (Phase 7, 2026-10-26)
- [Q-042] CSV type mapping, encodings, and duplicate keys are only in the edge cases. Default chosen: columns default to S. - [Q-043] Preview must not read a 512 MB file, and import progress has to survive navigation. Approval (2026-10-27): an error-report id is unguessable and bound to the session and connection. The file mode is 0600. Reports are deleted on shutdown. Another session gets 404. A multipart upload without `X-DS-CSRF` is rejected. (Phase 7, 2026-10-26)
