# Changelog

## 1.0.0-rc.1

Release candidate. The workspace version is `1.0.0-rc.1`. The release workflow builds a Docker image and the `dynamo-studio` tarball and uploads them as artifacts. It does not publish to a registry.

## 0.0.0

Work in progress before the 1.0.0 release candidate.

- Connect to DynamoDB Local or AWS, with read-only mode enforced on the server.
- Browse, query, edit, and undo items. PartiQL, import, and export.
- Command palette, shortcuts, light and dark themes.
- Non-root container image and a `dynamo-studio` command.
